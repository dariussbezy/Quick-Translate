# Quick Translate

Translate messages and drafts with Google, Microsoft, DeepL or Groq AI.

- Translate button in the composer, optionally translating before sending.
- Translate received messages, automatically in chosen chats.
- Google and Microsoft need no key. DeepL and Groq AI use your own API key (the settings explain how to get a free Groq key).
- Choose the order of the services: when one fails or is paused, the next one is used. By default services with a key come first, then Google, then Microsoft.
- Select part of a draft to translate only that part.
- Separate languages for outgoing and incoming messages, protected words and translation history.

## Install

Add this URL in **Settings → Plugins → Settings Icon → Repository URL**:

```text
https://raw.githubusercontent.com/dariussbezy/dariussbezy-Plugins/main/index.json
```

This repository holds the source and test builds of Quick Translate. All plugins are published together in [dariussbezy's Plugins](https://github.com/dariussbezy/dariussbezy-Plugins).
